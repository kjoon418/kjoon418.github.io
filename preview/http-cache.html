브라우저 캐시를 확인할 때는 리소스를 저장할 수 있는지와, 저장한 응답을 언제 다시 확인하는지부터 나누어 보면 쉽다.

유효 기간과 변경 여부를 확인한다

max-age가 지정된 응답은 유효 기간 동안 재사용될 수 있다. 서버에 다시 확인할 때 브라우저는 저장했던 ETag를 If-None-Match에 보낼 수 있고, 콘텐츠가 그대로라면 서버는 본문 없이 304 Not Modified를 응답한다.

Cache-Control: max-age=60
ETag: "article-v1"

개발자 도구에서 관찰한다

Network 탭에서 캐시 비활성화가 꺼져 있는지 확인하고 같은 리소스를 열어 본다. 전송 크기, 상태 코드, 요청과 응답 헤더를 함께 보면 어느 단계에서 응답을 재사용했는지 판단하기 쉽다.
