개요

GitHub Actions는 잘 적용 하셨나요?
CI/CD가 실패하면 바로 모든 팀원이 알아챌 수 있도록 Discork Webhook과 연결해 봅시다.

사전 작업

  1. 당연히 디스코드 채널이 있어야 합니다.
  2. 역할별로 멘션을 보내고 싶다면 개발자 모드를 켜주세요(Discord 앱에서 설정 → 고급 → 개발자 모드)

웹후크 만들기


톱니바퀴 버튼을 눌러서 채널 편집으로 들어가 주세요.
웹후크는 채널별로 만들어지기 때문에, 알림을 받고 싶은 채널을 골라주세요.


웹후크 만들기 버튼을 눌러서 웹후크를 만들고, 만들어진 웹후크의 URL을 저장해 두세요.

Actions secrets 추가하기

다음 Secrets를 추가해 주세요(이름은 달라도 괜찮아요)
1. DISCORD_WEBHOOK_URL (필수)
- 아까 저장한 웹후크의 URL을 입력해 주세요.
2. DISCORD_ROLE_ID (선택)
- 만약 멘션을 역할별로 보내고 싶다면, 역할 ID를 입력해 주세요.
- 역할 아이디는 '서버 설정 → 역할 → 기타 → 역할 ID 복사하기'에서 확인할 수 있어요(개발자 모드가 켜져 있어야 해요)

워크플로우 수정하기

jobs:
  build_and_push:
  	# ... 빌드하고 푸쉬 ...
    
  deploy:
  	# ... 배포 ...
    steps:
      # ... 배포 ...
      - name: Send Discord Notification
        if: always()
        run: |
          STATUS="${{ job.status }}"
          if [ "$STATUS" = "success" ]; then
            MSG="✅ CI/CD 성공!"
          else
            MSG="❌ CI/CD 실패! <@&${{ secrets.DISCORD_ROLE_ID }}>"
          fi

          RUN_URL="https://github.com/${{ github.repository }}/actions/runs/${{ github.run_id }}"
          curl -H "Content-Type: application/json" \
               -X POST \
               -d "{\"content\": \"${MSG}\n🔗 [로그 확인하기](${RUN_URL})\"}" \
               ${{ secrets.DISCORD_WEBHOOK_URL }}

위와 같이 맨 마지막 단계에 Discord 알림을 보내는 작업을 추가해 주세요.
job.status를 통해 작업 성공/실패 여부를 확인할 수 있어요.

<@& ROLE_ID > 형식으로 특정 역할을 멘션하게 만들 수 있어요.
Actions Secrets과 같이 쓰면 위와 같이 <@&${{ secrets.SECRET_이름 }}>처럼 적으시면 됩니다.

성공!

CI/CD에 문제가 없다면 이렇게 알림이 오는 것을 확인할 수 있어요 🥳
