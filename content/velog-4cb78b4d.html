인간이 세계를 이해하는데 사용하는 추상화 기법 3가지를 알아보자

분류와 인스턴스화

1. 분류란?

객체의 구체적인 세부 사항을 숨기고, 인스턴스 간에 공유하는 공통 특성을 기반으로 범주를 형성하는 과정이다

즉, 객체들의 특정 집합에 공통의 개념(Concept)을 적용하는 것을 의미한다

  • 우리는 ‘바퀴를 이용해 사람을 운반하는 운송수단’이라는 개념을 적용할 수 있는 객체 집합을 ‘자동차’라는 범주로 분류한다

우리는 분류를 통해 여러 개별 현상을 하나의 개념으로 다룬다
소프트웨어에서는 이 ‘개별 현상’을 객체라고 부르고, ‘하나의 개념’을 타입이라고 부른다

2. 인스턴스란?

  • 분류를 통해 형성된 범주로부터 객체를 생성하는 과정이다 분류의 역으로 볼 수 있다

3. 타입을 적용하기 위한 정의

객체를 어떤 타입으로 분류하기 위해서는, 다음 3가지 정의가 필요하다

  1. 심볼: 타입을 가리키는 간략한 이름이나 명칭
    • 타입을 쉽게 참조하고 커뮤니케이션할 수 있도록, 모호하지 않은 이름을 제공하는 역할을 한다
  2. 내연: 타입의 완전한 정의
    • 객체가 어떤 타입에 속하기 위해선, 해당 객체가 해당 타입의 내연을 완전히 만족해야 한다
  3. 외연: 타입에 속하는 모든 객체들의 집합
    • 어떤 객체가 내연을 만족한다면, 해당 객체는 해당 타입의 외연의 원소로 포함된다

일반화와 특수화

1. 일반화란?

범주 사이의 차이를 숨기고, 범주 간에 공유하는 공통적인 특성을 강조하는 과정이다

2. 특수화란?

범주 간의 차이를 강조하는 과정이다
일반화의 역으로 볼 수 있다

3. 슈퍼타입과 서브타입

일반화와 특수화를 사용하면, 범주(=개념=타입)와 범주간의 계층 구조를 구축할 수 있다

어떤 타입이 다른 타입보다 일반적이라면 해당 타입을 슈퍼타입(Supertype)이라 부르고, 어떤 타입이 다른 타입보다 특수하다면 해당 타입을 서브타입(Subtype)이라고 부른다

객체지향의 세계에서는 이를 다음과 같이 정의할 수 있다

  1. 서브타입은 슈퍼타입이 가진 본질적인 속성에 더해 자신만의 속성을 추가로 가진다
  2. 모든 서브타입들은 슈퍼타입의 속성을 공유한다

4. 100% 규칙과 is-a 규칙

‘100% 규칙’과 ‘is-a 규칙’이란, 어떤 타입이 다른 타입의 서브타입이 되기 위해서 준수해야 하는 규칙들이다

어느 타입이 다른 타입과 다음 규칙을 만족시키지 못할 경우, 두 타입 간에 일반화 관계는 성립하지 않는다

  1. 100% 규칙: 슈퍼타입의 정의가 100% 서브타입에 적용되어야 한다
  2. is-a 규칙: 서브타입의 모든 인스턴스는 슈퍼타입 집합에 포함되어야 한다(즉, subtype is a supertype 구문을 통과해야 한다)
    • 달리 말하면, 서브타입은 슈퍼타입의 부분집합이어야 한다

5. 상속: 서브타이핑과 서브클래싱

프로그래밍 언어로 일반화-특수화 관계를 구현하는 일반적인 방법은 상속이라는 매커니즘을 이용하는 것이지만, 모든 상속 관계가 일반화 관계인 것은 아니다

일반화 관계가 성립하기 위해서는, 서브타입이 슈퍼타입에 순응(Conformance)해야 한다
순응에는 다음과 같은 종류가 있다

  1. 구조적인 순응(Structural conformance)

    • 서브타입이 슈퍼타입의 내연을 준수해야 한다는 것을 의미한다
      즉, 위에서 언급한 100% 규칙을 준수하는 것이다
    • 구조적으로 순응해야만, 서브타입은 슈퍼타입을 대체할 수 있게 된다

  2. 행위적인 순응(Behavioral conformance)

    • 서브타입의 행위가 슈퍼타입의 행위를 대체할 수 있어야 한다는 것을 의미한다
      즉, 리스코프 치환 원칙(LSP)을 준수하는 것이다

모든 상속관계가 일반화 관계가 되지 않는 것은, 상속이 코드의 중복 제거와 재사용성을 위해 사용되기도 하기 때문이다(이 경우엔 서브타입이 슈퍼타입에 순응하지 않을 수 있다)
그 관점에서 상속의 용도를 다음 두 가지로 분류할 수 있다

  1. 서브타이핑(Subtyping)

    • 일반화 관계를 구현하기 위해 상속을 사용하는 것을 의미한다
    • 서브클래스가 슈퍼클래스를 대체할 수 있는 경우, 이를 서브타이핑이라고 한다
    • 흔히 인터페이스 상속(Interface inheritance)이라고 부른다

  2. 서브클래싱(Subclassing)

    • 코드의 중복 제거 및 재사용성을 위해 상속을 사용하는 것을 의미한다
      즉, 단순히 코드를 공유하기 위해 상속을 사용하는 경우이다
    • 서브클래스가 슈퍼클래스를 대체할 수 없는 경우, 이를 서브클래싱이라고 한다
    • 흔히 구현 상속(Implementation inheritance)이라고 부른다

코드를 유연하게 만들고 재사용성을 높이고자 한다면, 가능한 모든 상속 관계가 서브타이핑이 되도록 하자

집합과 분해

1. 집합이란?

부분과 관련된 세부 사항을 숨기고, 부분을 사용해서 전체를 형성하는 과정이다

즉, 추상화 메커니즘인 동시에 캡슐화 메커니즘이다

2. 분해란?

전체를 부분으로 분리하는 과정이다
집합의 반대 과정으로 볼 수 있다
