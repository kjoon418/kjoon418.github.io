# 글 관리

- 공개 글은 `content/`에 HTML 파일로 추가합니다. 첫 HTML 주석에 JSON으로 `title`, `summary`, `date`, `category`를 적고, 주석 뒤에 본문을 작성합니다. `category`는 `tech`, `daily`, `retrospect` 중 하나입니다.
- `summary`는 독자가 궁금해할 문제나 장면을 짧게 소개합니다. 기술·회고 글에는 읽고 나면 알게 될 방법, 원리 또는 판단 기준을 구체적으로 담습니다. 일상 글은 흥미로운 장면이나 맥락에 집중합니다. 제목이나 본문 문장을 그대로 옮기지 않습니다.
- `date`에는 `YYYY-MM-DD` 형식의 날짜 또는 `2026-11-12T07:10:00.588Z`처럼 밀리초를 포함한 UTC 발행 시각을 적습니다. 목록에는 서울 기준 날짜를 표시하며, 발행 시각이 있는 글은 상세 화면에 서울 시간도 표시합니다. 정렬할 때 날짜만 있는 글은 한국 표준시(UTC+09:00) 기준 그날 자정으로 처리합니다.
- 파일 이름에는 영문 소문자, 숫자, 하이픈을 사용합니다. 파일 이름이 `/posts/<파일명>/` 주소를 결정하므로 게시된 글을 수정할 때는 이름을 유지합니다.
- 표지가 필요하면 `assets/`에 이미지를 두고 `cover`에 `/assets/`로 시작하는 경로를 지정합니다. 표지에 본문 이해에 필요한 정보가 있으면 `coverAlt`를 작성합니다.
- 화면 확인용 글은 `preview/`에 둡니다. 공개 빌드에 포함되는 글은 블로그 작성자의 원고로 한정합니다.
